<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File system -> Import | JSON import reads external files that could contain malicious data |
| App -> File system | Backup/export writes to AppData and user-selected paths |
| UI -> Backup/Export | File dialogs allow user to select arbitrary paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-03-01 | Tampering | JSON import file | mitigate | Version field validation (D-19). Deserialize with System.Text.Json (no polymorphic deserialization). Reject files > 100MB. |
| T-03-02 | Information Disclosure | Export files | accept | User explicitly chooses export location. Data is user's own. No automatic network transmission. |
| T-03-03 | Denial of Service | Import large file | mitigate | Validate file size before deserialization. Stream-read instead of loading entire file into memory. |
| T-03-04 | Tampering | Backup file corruption | mitigate | SQLite VACUUM INTO creates atomic copy. Verify file integrity after backup (file exists, size > 0). |
| T-03-SC | Tampering | NuGet package installs | mitigate | No new packages in this plan. Existing lock file applies. |
</threat_model>
