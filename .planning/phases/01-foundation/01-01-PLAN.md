## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI -> ViewModel | User input (subject names) crosses from XAML to C# via data binding |
| Infrastructure -> SQLite | SQL queries generated by EF Core; parameterized by default |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-01-01 | Tampering | SQLite database file | accept | Local-only app, single user, no network exposure. File-level tampering requires local access already. |
| T-01-02 | Information Disclosure | Log files (Serilog) | mitigate | Serilog writes to AppData, no sensitive data (API keys, passwords) logged. Logs contain only operational data. |
| T-01-SC | Tampering | NuGet package installs | mitigate | All packages from verified NuGet.org with HIGH confidence ratings per STACK.md. Lock file (packages.lock.json) enables reproducible restores. |
