   - AddChapterAsync(subjectId, name, sortOrder): creates chapter under subject (per SUBJ-04).
   - UpdateChapterAsync(id, name, sortOrder): updates chapter.
   - DeleteChapterAsync(id): deletes chapter and its knowledge points.
   - AddKnowledgePointAsync(chapterId, name, description, sortOrder): creates knowledge point under chapter.
   - UpdateKnowledgePointAsync(id, name, description, sortOrder): updates knowledge point.
   - DeleteKnowledgePointAsync(id): deletes knowledge point.
   - GetBySubjectAsync(subjectId): returns chapters + knowledge points for a subject.

| ViewModel -> Service | Business logic validation in service layer, not UI |

| T-02-SC | Tampering | NuGet package installs | mitigate | No new packages added in this plan; existing lock file applies |
